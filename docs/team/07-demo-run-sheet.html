The hand overs

  2. Tiya to Kinjal. "The student is signed in and lands on a dashboard that says the profile is incomplete. Kinjal will show how the pages work and finish the profile."
  3. Kinjal to Chandra. "With a complete profile the student can look at the drives. Chandra will show how the app decides what they can apply for."
  4. Chandra to Yuvraj. "That application is now a row in MySQL. Yuvraj will show how the app reaches the database and prove the row is there."
