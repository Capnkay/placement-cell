Pick a layer. You own the whole thing

Nobody explains code somebody else wrote. Each layer has a full "be ready to explain" list waiting in WORK-SPLIT.md.

Layer 1

Domain model and persistence

The JPA entities and how they become tables. The relationships, which side owns each foreign key, Hibernate named as the provider, and the seeder that fills an empty database on first start.

Layer 2

JDBC, connectivity and reporting

Everything about reaching the database. The connection pool, the prepared statements, the hand written transaction, and the Reports and Database pages that read the live schema from the driver itself.

Layer 3

Servlets, session and security

Who is asking, are they allowed, where does it go. Sign in and sign out, the filter in front of every page, password hashing, the non blocking upload, the guarded download.

Layer 4

Presentation, validation and rules

All 18 screens, the stylesheet, every server side input rule, and the eligibility policy written as pure logic so it can be tested with no database at all.

The build scripts and a handful of service beans were shared work. If asked, say so. It is listed at the bottom of WORK-SPLIT.md.
